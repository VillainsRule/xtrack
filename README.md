<div align='center'>
  <h1>xtrack</h1>
  <h3>a small CLI utility for your Apple Music library</h3>
</div>

<br><br>

### features
- change the play count of a track
- change the skip count of a track
- find orphans (songs not in playlists)

<br><br>

### setup
1. `git clone https://github.com/VillainsRule/xtrack && cd xtrack`
2. `bun install` (node also supported)
3. `bun .`
